# Hamann & Kollegen Landingpage

Statische Landingpage mit lokal gespeicherten Schriften und Bildern. Die Videos werden von Vimeo geladen.

## Netlify

Repository mit Netlify verbinden. `netlify.toml` definiert das Veröffentlichungsverzeichnis `wireframe/perspective-abstrakt`. Kein Build-Befehl erforderlich. Produktionsbranch: `main`.

## Bearbeitung

- `wireframe/perspective-abstrakt/index.html`: Seiteninhalt
- `wireframe/perspective-abstrakt/script.js`: Testimonials, FAQ und Interaktionen
- `wireframe/perspective-abstrakt/hamann-light.css`: Hamann-Design

## Aktueller Stand

Die Seite ist ein Entwurf. CTA-Buttons öffnen eine Vorschau der Gesprächsanfrage; es werden noch keine Leads erfasst. Die Formular-/Terminbuchungsintegration sowie letzte Platzhalter und die uneinheitliche Angabe 20/30 Minuten sind vor Kampagnenstart zu vervollständigen.
